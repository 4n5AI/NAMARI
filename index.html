    生成した音声

    生成した音声の扱いは、Gemini API 利用規約に従ってください。生成音声には Google の SynthID による電子透かしが入ります。

    送信するデータ

    入力したテキストとAPIキーは、Gemini API（generativelanguage.googleapis.com）以外には送信しません。キーと履歴（生成した音声）はこのブラウザにだけ保存され、いつでも削除できます。方言の変換と読み上げのリクエストは、Google 側に保存しない設定（store: false）で送っています。
