        アプリとして入れる

        ホーム画面やデスクトップに入れて、アプリのように使えます。オフラインでも、履歴の再生・保存と動画の書き出しが使えます。

        作成した方言の声

        方言×声の組み合わせごとに、初回だけ Voice design で声を作り、このブラウザに記録しています（Google 側に1年間保存・1プロジェクト200件まで）。

        使い方

        はじめに（最初の1回だけ）

        1. Google AI Studio で Gemini API キーを取得します。
        2. 「設定」タブにキーを貼り付けて「保存」を押します。
        3. おすすめ：Google Cloud コンソールで、キーに HTTPリファラー制限をかけます（「設定」タブに手順があります）。

        基本の3ステップ

        1. 01 テキスト：読み上げたい文章を標準語で書きます（1000文字まで）。笑い・ため息・間などは、下のボタンからタグで入れられます（「その他のタグ」で36種類）。
        2. 02 方言：地方のタブから方言を選び、強さ（弱・中・強）を決めて「変換」を押します。変換後の文章は手で直せます。
        3. 03 声：声（自動・女性／男性・若め／年配・自分の声）、感情、モデルを選んで「音声を生成」を押します。

        「変換」を押さずに「音声を生成」を押しても、自動で方言に変換してから読み上げます。

        できあがった音声

        • 波形をクリックすると、その位置から再生します。
        • 「WAVをダウンロード」で保存できます。生成した音声は、このブラウザの「履歴」に最新20件まで残ります。
        • 「縦型動画（MP4）」で、字幕付きの 9:16 動画を書き出せます（TikTok・リール・ショート向け）。

        方言の声について

        方言と声の組み合わせごとに、初回だけ、その土地の話し方をする声を作ります（数十秒かかります）。2回目からはすぐに使えます。作った声は「設定」タブから削除できます。

        自分の声で読み上げる

        1. ステップ03の「自分の声を登録・管理」を開きます。
        2. 例文を読んで10〜30秒録音し、続けて同意文を読み上げて録音します。
        3. 名前を付けて登録すると、「声」の欄で選べるようになります。

        登録できるのは、あなた自身の声だけです。

        アプリとして使う（PWA）

        NAMARI は、ホーム画面やデスクトップに入れて、アプリのように使えます。

        • Chrome・Edge（PC・Android）：「設定」タブの「アプリとして入れる」、またはアドレスバーのインストールのアイコン
        • iPhone・iPad：共有ボタン →「ホーム画面に追加」
        • Mac の Safari：「ファイル」→「Dockに追加」

        「設定」タブの「アプリとして入れる」からも入れられます。

        オフラインでも、履歴の再生・保存、動画の書き出し、この使い方は使えます。変換と読み上げは Gemini API を使うので、ネット接続が必要です。iPhone・iPad のホーム画面のアプリは Safari と保存場所が別なので、アプリ側で APIキーをもう一度入力してください。

        困ったとき

        「APIキーが正しくありません」と出る
        「設定」タブでキーを貼り直してください。リファラー制限をかけている場合は、このページのURLが許可されているかも確認してください。
        「リクエストが多すぎます」と出る
        無料枠の上限か、一時的な混雑です。少し待ってから試してください。
        方言の声を作れなかった
        その回は既定の声で読み上げます。時間をおいて、もう一度生成してください。
        録音できない
        アドレスバーの設定から、このサイトにマイクの使用を許可してください。
        動画を書き出せない
        Chrome・Edge・Safari の最新版で開き、サイズを「720×1280（軽量）」にして試してください。

        AI連携

        ChatGPT や Claude などの AI から NAMARI を使う方法は2つあります。

        A
        MCPClaude デスクトップ版・Claude Code など

        AI に「この文を博多弁で読み上げて」と頼むだけで、方言の音声（WAV）があなたのPCに保存されます。

        B
        リンクChatGPT・Claude・Gemini など、どのAIでも

        AI に NAMARI のリンクを作ってもらい、開くと入力済みの状態になります。

        A. MCP：Claude デスクトップ版（おすすめ）

        1. namari.mcpb をダウンロードします。
        2. ダウンロードしたファイルを開くと、Claude のインストール画面が出ます（Claude の「設定」→「拡張機能」にドラッグ＆ドロップしても入れられます）。
        3. 「Gemini API キー」と「保存先フォルダ」を入力して、有効にします。
        4. チャットで頼みます。例：「今日はとても暑いですね」を博多弁で読み上げて

        音声は、保存先フォルダの中の「NAMARI」フォルダに WAV で保存されます。APIキーは Claude の設定（このPC）に保存され、NAMARI のサーバーはありません。

        A. MCP：Claude Code・そのほかの MCP クライアント

        Node.js 18 以上が必要です。リポジトリを取得して、MCP サーバーとして登録します。

        git clone https://github.com/4n5AI/NAMARI.git
claude mcp add namari -s user -e GEMINI_API_KEY=あなたのキー -- node "$(pwd)/NAMARI/mcp/server/index.js"

        設定ファイル（JSON）で登録するアプリの場合：

        {
  "mcpServers": {
    "namari": {
      "command": "node",
      "args": ["/NAMARIを置いた場所/NAMARI/mcp/server/index.js"],
      "env": { "GEMINI_API_KEY": "あなたのキー" }
    }
  }
}

        コマンドに書いたキーはシェルの履歴に残ります。気になる場合は、あとで履歴から消してください。

        MCP でできること

        speak方言に変換して読み上げ、WAV を保存（自分の声・感情・モデルも指定できます）
        convert_to_dialect方言の文章だけを作る
        list_dialects方言・声・感情・タグの一覧
        list_voices自分の声（Google に保存したもの）の一覧
        make_namari_linkNAMARI を入力済みで開くリンクを作る（字幕付き動画を作りたいときなど）

        MCP で自分の声を使うには、NAMARI の「自分の声を登録」で「Google に保存」を選んでください。

        自分の声（Voice replication）
        
    
        登録できるのは、あなた自身の声だけです。他人の声を、本人の同意なく複製しないでください。録音した音声は声の登録のために Gemini API にだけ送信し、このブラウザには保存しません（保存するのは声のIDまたはキーだけです）。「Google に保存しない」を選んだ場合のキー（voicekey_...）は、持っている人なら誰でもその声を使えるため、他人に共有しないでください。
        
    
        縦型動画（MP4）

        方言について
        
    
        方言への書き換えと発音は AI によるもので、実際の話し方と違う場合があります。「β」の方言は特に不安定です。変換後のテキストは手で直してから読み上げられます。
